# AxiomGuard 0.6.1

AxiomGuard 0.6.1 is the recommended release for the 0.6 line.

This release expands AxiomGuard from a collection of focused backend security helpers into a broader application-security toolkit for Node.js and TypeScript services, while keeping the package modular and free of runtime dependencies.

## Highlights

### Browser request protection

A new request-policy module helps protect unsafe browser requests using Fetch Metadata signals with exact-Origin fallback. It is designed to work alongside CORS and CSRF controls without changing machine-to-machine APIs unless explicitly enabled.

### Idempotency protection

AxiomGuard can now normalize idempotency keys, generate request fingerprints and bind a key to the request semantics that first claimed it. In-memory and Redis-backed stores are available for single-instance and distributed deployments.

### Provider-aware webhook verification

Webhook support now includes:

- GitHub signed deliveries with replay protection
- Stripe signature and freshness validation
- Slack signed-request verification
- Meta/WhatsApp `X-Hub-Signature-256` verification
- generic HMAC helpers for custom providers

### Safer outbound requests

`safeFetch()` and URL/DNS validation helpers provide guardrails around user-influenced outbound requests, including redirect validation, credential stripping across origins, bounded redirects and request timeouts.

### Framework integration

Security adapters are available for Express, Fastify and Hono, with Redis integrations for shared replay, rate-limit and idempotency state.

### Repository secret scanning

The `axiomguard` CLI supports repository scanning with human-readable output, JSON, SARIF and reviewed baselines while avoiding disclosure of matched credential values.

## Install

```bash
npm install @axiomnode-lab/guard
```

The package is available publicly from npmjs under the `@axiomnode-lab` scope.

## Example

```ts
import { createExpressSecurityMiddleware } from '@axiomnode-lab/guard/adapters/express';

app.use(createExpressSecurityMiddleware({
  cors: {
    origins: ['https://app.example.com'],
    allowCredentials: true,
    allowMethods: ['GET', 'POST', 'PATCH'],
  },
  requestPolicy: {
    allowedOrigins: ['https://app.example.com'],
  },
}));
```

## Upgrade note

Users on `0.6.0` should move to `0.6.1`, particularly when using the `axiomguard` CLI. Version `0.6.1` contains the corrected package metadata for the executable entry point.

Library consumers can otherwise upgrade normally:

```bash
npm install @axiomnode-lab/guard@0.6.1
```

## Security boundaries

AxiomGuard provides reusable security controls, but it does not replace authentication, authorization, a WAF, a secrets manager, outbound network policy, durable application transaction storage or an application-specific security review.

See [SECURITY.md](../../SECURITY.md) and [THREAT_MODEL.md](../../THREAT_MODEL.md) for security reporting and design boundaries.
