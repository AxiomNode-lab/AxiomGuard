# AxiomGuard 0.6.2

AxiomGuard 0.6.2 refreshes the public package presentation for the 0.6 line.

The package now ships with the current user-facing README used by the repository, removing outdated release-process and internal qualification details from the registry package page.

## Install

```bash
npm install @axiomnode-lab/guard@0.6.2
```

## Compatibility

There are no runtime API changes in this patch. Existing `0.6.1` integrations can upgrade without code changes.
