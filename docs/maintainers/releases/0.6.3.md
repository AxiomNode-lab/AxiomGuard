# AxiomGuard 0.6.3

AxiomGuard 0.6.3 improves the package documentation so developers can understand how to install and use the library directly from the registry page.

## Documentation improvements

- Added a copy-paste Express quick start.
- Added Fastify and Hono integration examples.
- Added a goal-oriented import guide for the public modules.
- Added practical recipes for API keys, signed webhooks, guarded outbound requests, idempotency, rate limiting, environment validation and safe logging.
- Expanded CLI usage with `npx axiomguard` examples.
- Corrected public examples to use the actual exported names `createApiKey` and `createFastifySecurityHook`.
- Clarified Node.js and ES module requirements.

## Install

```bash
npm install @axiomnode-lab/guard
```

This patch changes package documentation and metadata only. Runtime security behavior and public APIs are unchanged.
